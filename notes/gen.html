Trust Wallet Deep Link Generator

Your deployed Cloudflare Pages URL. This gets wrapped in trustwallet://open_url
Fixed for Tron mainnet. Don't change unless you know what you're doing.

Usage

Chat/Telegram: Send the generated link directly. When victim taps on mobile with Trust Wallet installed, it opens the URL inside Trust Wallet's in-app browser (wallet already unlocked).

QR Code: Use qr/qr.html with the same site URL. Trust Wallet's QR scanner opens the link directly in-app — no deep link wrapper needed.

Format: trustwallet://open_url?coin_id=20000714&url=ENCODED_URL
